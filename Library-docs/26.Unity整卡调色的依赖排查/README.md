# 26 · Unity 整卡调色的依赖排查

R65 的仙人掌手牌和收藏图都能预览，整卡保存却被战场上的外部覆盖动画拦住。桌球大鳄尸遇到相反的情况，通用手牌预览因为来源校验显示空白，整卡调色已能预览并保存。这两条路径各自需要验证不同的 Unity 对象和来源。排查时先记下失败入口、资源族及第一个拒绝条件。

本章记录 R66–R72 的代表案例。测试卡表涉及玩家数据的副作用见[测试卡表触发牌组清理](01.测试卡表触发牌组清理.md)。手机入口和更早的保存排障见[第 24 章](../24.启动器工作台与手机编辑/README.md)。

## 从失败入口追到原生引用

| 样本 | 首个阻断或实际现象 | 已验证做法 |
| --- | --- | --- |
| 仙人掌、小伙伴 · R66 | 战场使用外部 `Character_special` 覆盖片段。静态卡面可以预览。 | 由活动清单核验供体，将原片段复制到新卡的战场 UnityFS，重绑新卡控制器的对应动作。采样率、曲线、帧事件、动作键和共享基础控制器引用保留。手机离线战斗分别看到攻击和治疗结算。 |
| 钢木兰、甜土豆、丰饶玉米角 · R67–R68 | Renderer 直接指向其他资源包的 Sprite。 | 核对供体 Bundle、CAB、Sprite 与 Texture2D，把匹配的 Sprite 和纹理复制到新卡包内，只重绑新卡的 Renderer。R68 的 24 张新模板全部通过两代本机保存和重开，甜土豆、丰饶玉米角另有手机与离线对局结果。 |
| 小喷菇、南瓜壳 · R69 | 本地动画按帧引用外部 Sprite，单改 Renderer 会漏掉运行中换图的帧。 | 按原动画片段和帧引用定位目标，只重绑副本中的对应帧。检查帧顺序、空帧及其他绑定和事件。离线录屏看到了小喷菇攻击中的口部换图和南瓜壳的组队光效。 |
| 火豌豆射手、火炬树桩 · R69–R70 | ETC2 解码通过后仍被预算拦住。两个战场资源族分别需要约 2.89 MB 和 2.96 MB 的解码像素，均超过当时每族 2 MiB。 | R70 按解码后的 RGBA 像素实施每族 3 MiB、整卡 6 MiB 的预算。核对原压缩供体和解码结果后，保存写入新卡的 RGBA32 副本。手机与本机参考解码器对这两张卡使用的 7 个 ETC2 供体产生相同像素指纹。 |
| 双生向日葵 · R70–R71 | 根节点 Renderer 通过原版材质引用本地 `Sprites/Default` Shader，触发依赖检查。 | 查清根节点的初始 Sprite、纹理槽及动画引用后，R71 保留同包原材质和 Shader。手机保存的包回读确认原对象字节保留，离线对局记录了原版和调色副本各产 2 阳光。附加探针未返回实战实例动态赋值数据。 |
| 向日葵、双人菇 · R72 | 部分战场图像仍引用活动清单中的官方外部 Sprite。 | 保留可核验的原引用和原色，修改包内可写纹理、手牌和收藏图。两张样本分别保留 2 处和 41 处外部引用，完成两代保存、冷重开和离线对局。其他 Mod 覆盖同一官方依赖的情况未测试。 |

### 桌球大鳄尸的空白手牌仍待处理

R70 从「卡牌编辑 → 基础 → 查看卡牌图片 → 手牌图」可复现空白和「图片暂不可用」。该手牌资源含可解码的 256 × 256 ETC2 纹理，但 Sprite 留有图集导入标签、空图集指针，包内也没有对应图集。通用预览在解码前因来源证据不足而拒绝。切回收藏图恢复，R69 的整卡调色入口也已验证手牌预览、两代保存和重开。后续评估通用预览时，要先核对官方原件、唯一的 Sprite／Texture2D 关系及完整画布。这项预览修正截至 R72 尚未完成。

## 验收时逐项回答

1. **实际用了什么资源。** 从模板 GUID、完整 Prefab 名、逻辑资源族和活动 Manifest 找到供体。追到包、CAB 和对象指针。确认失败出在 Renderer 引用、动画帧、图集来源、材质还是纹理预算。
2. **保存实际改了什么。** 首次保存、冷重开、第二次保存并再次读回。核对副本引用、贴图像素和原对象字节。重绑动画时另比对未编辑帧及事件。旧版可原样导入和导出、能否继续编辑应分别执行。R71 可原样进出代表 R72 的 ZIP，但拒绝重写那批部分调色变体。
3. **进入游戏后实际发生了什么。** 用同一局对照原版与副本的手牌和战场。针对案例选择能观察的事件，例如一次换图、一次治疗、一次产阳光或生成卡牌。逐项记下出现与未观察到的行为。R70 的布阵中原版和调色版火炬树桩均未观察到攻击加成，因此该轮只确认了两版外观及火豌豆射手攻击。

R72 的结构扫描覆盖 503 个模板，其中 190 个沿用此前方案，193 个通过部分调色的结构检查，另有 120 个仍受其他原生资源条件限制。部分调色的手机保存和离线行为记录覆盖表中两张代表卡。游戏内收藏网格、动作音效和联网对局仍按各候选的实测范围查阅。
