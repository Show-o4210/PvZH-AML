# 25 · 游戏语言资源与双包分发

R75 RC1 在 Pixel 6 上离线启动原版时，原引擎已读到越南语文字和字体，画面仍停在连接错误页。同一隔离用户后来以在线模式进入主菜单，引擎读回的实际语言仍是 `vi`。排查时分别核对启动器语言设置、游戏资源与引擎实际语言，以及游戏网络连接。

本章沿用[第 20 章的资源准备与同步流程](../20.工程体验跃迁-资源门卫与教程跳过/README.md)，记录 R75 的语言复拷和 R76 的全量／标准双包试用。[候选验收摘要](../24.启动器工作台与手机编辑/05.当前版本能力.md#r74-r77-development)

## 选择了越南语，游戏仍显示旧文字

1. 在「设置 → 通用 → 语言」选择越南语。R75 在选择或重选当前语言时都会从启动器管理的独立来源重新复制所需资源。Pixel 6 首次选择与重选均确认复制了文字和字体两个文件。
2. 核对当前活动的官方 Manifest、目标缓存和两份资源指纹。语言来源与游戏读取的缓存各有自己的职责。先校验两份待复制资源再应用，避免只写了文字就发现字体缺失。R75 的本机回归覆盖复制中断、来源文件损坏修复、保护无从确认归属的目标文件，以及已启用的中文 Mod 来源。
3. 完全退出游戏并重新启动。确认原引擎读回的实际语言、文字、字体和字形材质。R75 与 R76 的越南语实测均记录了 12 套字体材质。原有越南语文本没有覆盖的字串仍可能使用英文。
4. 如果实际语言和资源指纹已核对，但仍停在连接错误页，单独检查隔离用户的联网环境。R75 的在线复验进入了主菜单。离线复验的证据停在引擎加载这一层。

### 官方清单变化时复核兼容

R75 比对了官方清单 11065 与 11066。8,015 个资源地址一致，2,880 条 Bundle 明细中有四条变化，分别是两个场景、`data_assets` 和 `pvpdata`。本次复用了已经验证的越南语文字和字体资源，并验证派生清单的 JSON、BIN 和实际缓存能互相对应。判定依据包括两份官方清单的精确指纹和资源差异。再次遇到官方更新时，应对新清单重新做这项核对。

## 全量包与标准包的首装

R76 RC1 两包都只含 `arm64-v8a`，共用 Android 包名、版本码和签名。官方资源清单均为 11066。包内 Bundle 数量与 APK 大小如下。

| 包型 | 包内官方 Bundle | APK 大小 | Pixel 6 全新安装 |
| --- | ---: | ---: | --- |
| 全量版 | 2,880 | 854,488,165 字节 | 在没有已下载快照的情况下，从 APK 复制全部目标，离线原版加载越南语文字、字体和材质。 |
| 标准版 | 61 | 265,935,176 字节 | 从首页「下载官方资源」补齐。复用包内 61 个，从官方 CDN 下载 2,819 个，共 674,906,786 字节。核验全部 2,880 个目标后，离线原版加载了同一组越南语资源。 |

标准版保留启动所需资源及依赖。本机测试用中断的响应复现断点续传。重试时校验 HTTP `206` 的 `Content-Range`，服务端回完整 `200` 时从头写。文件完成后再检查长度、UnityFS 文件头和固定 SHA256。测试也验证了错误哈希和半份响应都无法提交下载快照，已经校验的暂存资源可重用，活动缓存里的未知文件仍保留原字节。

## 双向覆盖后的验收

在同一隔离用户里，以正常覆盖安装切换全量版和标准版。两种方向都核对包型、活动 Manifest、资源就绪状态和缓存复用。R76 实测保留越南语设置、离线选项、官方资源和 Mod 库，切换后没有重新下载 Bundle。仅看首页提示无法确定实际取到了哪份资源，测试还比对了安装包、受检资源及 Mod 库指纹。

标准版准备完成后的另一轮测试验证了卡牌换阵营保存与冷重开读回，打开了植物任务 001 的战场布局，也显示了一张官方 Unity 贴图。关卡与美术覆盖到读取预览。R76 的试验未覆盖正式对局、其他设备 ABI 组合或真实 GitHub APK 分发。[分层结果](../24.启动器工作台与手机编辑/05.当前版本能力.md#r74-r77-development)

### 复核记录

工作区 R75 RC1 的 `evidence/validation.json` 记录语言来源、首次／重选复制和离线／在线启动结果。R76 RC1 的 `evidence/validation.json` 和 `evidence/standard-post-download-smoke.json` 记录双包首装、覆盖和次轮冒烟。断点续传、错误指纹、原缓存保留的证据来自 R76 本机 `StandardResourcesTest`。
